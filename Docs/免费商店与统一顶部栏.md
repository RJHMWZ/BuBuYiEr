# 免费商店与统一顶部栏

2026-11-16

主菜单、每日奖励、图鉴、商店和设置共用 `SharedHeader`。切换页面只切换左侧“关卡 / 返回”，右侧金币栏使用同一个对象、字体、尺寸和美术，不再受各面板缩放影响。顶部栏会随刘海和底部手势安全区调整。加号显示通关和每日奖励的金币来源。

每日奖励和设置面板右上角的关闭叉号及对应点击区域已删除，统一使用顶部“返回”。

商店只有游戏金币支付，分类为全部、装扮、皮肤、道具。原人民币礼包已经移除，目前商品目录为空；添加商品后自动生成列表，超出一屏可以上下滑动。

## 添加商品

在 `Assets/BuBuYiEr/UI/BearShopCatalog.asset` 的 `Items` 中添加：

- `Id`：永久唯一标识，例如 `decoration_red_bow`，发布后不要修改。
- `Title / Description / Icon`：商品名称、说明、图片。
- `Category`：Decoration（装扮）、Skin（皮肤）、Item（道具）。
- `Coin Price`：正整数金币价格。
- `Available`：是否上架。未上架、无效配置及重复 ID 都不允许购买。
- `Consumable`：不勾选时只能购买一次；勾选后可重复购买并累计库存。

已有菜单会在每次打开商店时读取目录，无需手工复制商品 UI。商品目录通过 `BearMenuArt.shopCatalog` 绑定，也可创建新的 Coin Shop Catalog 资源替换它。

购买会将金币扣除与库存增加一起写入原有玩家存档，并立即落盘；余额不足不扣款，非消耗品重复点击不重复扣款。查询库存使用 `BearCoinShop.Quantity(id)`。后续装扮穿戴、皮肤替换、道具效果需接入对应玩法；当前尚未提供这些内容，不会出售无效果的占位商品。

## 清理及手机适配

已删除内购、广告控制器与界面、人民币礼包和广告按钮素材、支付配置、广告依赖解析器，以及五张已无用途的完整菜单参考图。保留实际使用的 SceneArt / SettingArt / DailyArt / ShopArt / CollectionArt 图集。每日奖励与顶部金币共用同一个金币和爱心图标。

已移除 Unity Ads、Unity Purchasing 包及其专用间接依赖，关闭广告、内购和分析的自动启动，清除 Android Gradle 中残留的广告原生库和架构排除项。旧存档中的历史字段仅用于保持兼容，不再驱动任何付费或广告功能。

菜单支持 Android 返回键关闭提示、从子面板返回主页；切后台会保存设置。商店长列表支持触摸滚动；沿用现有玩法的拖动取消点击、失焦暂停和安全区布局。

预制体及 Home 场景已经重新生成。之后需要整体重建时，使用 `Tools > BuBuYiEr > 重建统一菜单与金币商店`。重建会更新生成的菜单预制体与场景实例，请先保存其他场景编辑。

## 验证结果

Unity 2022.3.62f3c1 独立副本通过金币交易与旧存档兼容、五页共用顶部栏在五种屏幕比例下的位置一致性、模拟刘海安全区、商品列表与分类、实际购买按钮、触屏回放及原有通关流程回归。Android ARMv7 / ARM64 IL2CPP APK 打包通过；检查 APK 权限与依赖，未包含支付权限和广告/内购 SDK。未连接 Android / iOS 真机，也未进行 iOS 打包验证。
