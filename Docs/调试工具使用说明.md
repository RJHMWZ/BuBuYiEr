# 开发调试工具

当前版本适用于糖果打砖块。打开 **Tools → BuBuYiEr → 开发调试面板**，从主页启动；运行时按 F1 或点击“调试 F1”显示面板。

- 指定关卡、上一关、下一关、重试：根据 `Resources/Levels/Level_编号.asset` 载入糖砖配置。
- 自动打本关、连续自动打关：实际点击糖砖，使用本关蜂蜜购买六种小球并升级，以真实伤害和碰撞完成棋盘；不会直接清空棋盘或强制胜利。
- 模拟胜利、失败：走实际结算 UI，方便验收；使用试玩模式，不修改正常关卡进度和星级。
- 暂停与 0.25x～4x 倍速：面板显示时游戏暂停；关闭后应用选中的倍速。
- 金币、存档备份、恢复、新玩家重置和日志导出继续可用。

旧的五种罐子道具调试入口已移除。蜂蜜、小球数量和等级属于本关，重试后重新准备；金币和玩家进度继续使用原存档。

试玩与自动打关不保存关卡进度、不发放通关金币，不触发关卡状态对应的插屏广告。返回主页清除试玩关卡覆盖。正常关内重试和下一关仍使用玩家进度流程。

备份只操作 `CBGAMES_PLAYER_DATA` 与 `BUBUYIER_DEBUG_PLAYER_BACKUP`，不删除其他游戏数据；覆盖备份、恢复和重置仍需要工具界面确认。发布包不勾选 Development Build 时，调试工具会被条件编译排除。

实现文件为 `Scripts/Debug/GameDebugService.cs`、`GameDebugPanel.cs`、`GameDebugAutoPlayer.cs` 和 `Scripts/Editor/Tools/GameDebugWindow.cs`。

玩法与关卡编辑详见 [糖果打砖块玩法说明](糖果打砖块玩法说明.md)。
