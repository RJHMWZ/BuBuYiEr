# 糖砖皮肤

默认糖砖统一使用草莓奶霜外观：浅粉渐变、细玫瑰色边缘、奶白高光和两侧小爱心。普通砖和大糖砖共用同一个绘制入口，不再根据关卡、位置、血量或 `Brick.Color` 分配纹理。受击保留短暂闪白；薄荷持续伤害以右上角小绿点表示。碎屑跟随皮肤的点缀色。

默认配置：`Assets/BuBuYiEr/Gameplay/Resources/CandyArt/BrickSkins/Default.asset`。可直接在 Inspector 调整表面渐变、边缘、底部、点缀和数字颜色，以及 `motif` 装饰形状。关卡布局、伤害、耐久与奖励不受影响。

## 后续添加商店皮肤

1. 在该目录内右键 **Create → BuBuYiEr → Brick Skin**，创建配置，例如 `brick_peach.asset`，设置颜色和装饰形状。文件名作为永久商品 ID，发布后保持不变。
2. 在 `Assets/BuBuYiEr/UI/BearShopCatalog.asset` 的 `items` 中增加商品：`id = brick_peach`、`category = Skin`、`effect = BrickSkin`、`consumable = false`，填写名称、说明、价格和解锁关卡。
3. 商店会使用与关内相同的绘制器显示糖砖预览；购买后自动装备，支持卸下、重新装备和存档。所有砖块共用玩家当前装备的皮肤。小球皮肤、桌面装扮与糖砖皮肤分别保存。

未装备、旧存档没有糖砖字段、或配置资源缺失时均使用免费默认外观。

`CandyBrickArt.Draw` 是关内和商店共用的造型入口；新造型可在此扩展。`CandyBrickSkin` 负责配色配置与缓存，商店根据商品 ID 加载 `Resources/CandyArt/BrickSkins/<id>`。
