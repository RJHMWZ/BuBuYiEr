# 小熊主菜单

当前版本使用统一顶部栏和免费金币商店，详细商品配置见 [免费商店与统一顶部栏](免费商店与统一顶部栏.md)。内购、广告及人民币礼包已经移除。

## 打开与编辑

1. 打开 `Assets/Diamond_Loop/Scenes/Home.unity`，无需 Play 即可预览菜单。
2. 选中 `HomeMenuCanvas`，Inspector 的“编辑模式页面预览”可切换主菜单、每日奖励、图鉴、商店、设置；编辑预览不会读写玩家存档。
3. 五个页面位于 `BearMenuUI` 下。共用顶部栏位于同级的 `SharedHeader`，修改一次即可应用到所有页面。
4. 场景菜单是 `Assets/BuBuYiEr/UI/Prefabs/BearHomeView.prefab` 的实例。运行时复用该实例；返回主页会清除新场景中的重复菜单与 EventSystem。
5. 整体重建使用 `Tools > BuBuYiEr > 重建统一菜单与金币商店`。这会覆盖生成的菜单层级，布局调整应写入 `BearMenuFactory` 对应文件。
6. SceneArt、SettingArt、DailyArt、ShopArt、CollectArt 的独立重建入口仍可使用。它们会更新对应预制体内容；需要同步替换场景实例时可整体重建。

## 界面与美术

主菜单正文设计尺寸为 1024×1536，子页正文为 941×1672。正文随安全区适配，长屏增加可用内容高度，横屏居中显示。共用顶部栏独立按 1024×1536 基准计算，切换页面不会随正文缩放而变化。

`SceneArt.png` 提供顶部栏、标题、双熊、房间、导航和花草；`SettingArt.png` 提供通用面板、滑条及设置图标；`DailyArt.png` 提供奖励卡片；`ShopArt.png` 提供分类标签、列表和金币购买按钮；`CollectionArt.png` 提供图鉴。相同 UI 直接引用相同精灵，面板和桌面使用九宫格缩放。已删除不用的完整参考图。

中文采用站酷快乐体，数字采用 Baloo 2；字体许可保存在 `Assets/BuBuYiEr/UI/Fonts/`。

## 已接入行为

- 开始按钮进入糖果打砖块；顶部星星打开选关。
- 顶部金币显示真实钱包，加号说明金币来自通关和每日奖励。
- 每日奖励保留七天循环、24 小时冷却及重复领取检查。
- 图鉴展示表情、故事及动画分类，解锁进度与关卡关联。
- 金币商店读取 `BearShopCatalog.asset`，支持分类、长列表滚动、余额检查、持久库存及非消耗品防重复购买。目前目录为空，待添加实际商品。
- 设置保存音效、音乐、震动与通知偏好。`BearMenuArt` 的 `privacyUrl / supportUrl` 可配置真实网页，留空时显示未开放。
- Android 返回键关闭信息提示或从子页返回主页；切后台保存设置。

主题每日奖励物品仍沿用 `BUBU_UI_EXTRA_` 存储；金币商店库存随 `CBGAMES_PLAYER_DATA` 存档一起保存。未来装扮穿戴和道具效果需要接入相应玩法。

玩法说明见 [糖果打砖块玩法说明](糖果打砖块玩法说明.md)，已有调试面板与自动打关工具保留。
