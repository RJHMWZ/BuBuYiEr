# 小球主题皮肤

球皮肤现在表示一套共享的材质主题，每种球仍有自己的主色和球种标记。奶霜曲奇、果冻泡泡、焦糖流星、星光棱晶四个已有商品 ID、价格、解锁关卡及玩家购买记录均保留，已有皮肤直接应用新外观。

| 球种 | 保留的颜色特征 | 球种标记 |
| --- | --- | --- |
| 奶糖球 | 奶黄、金黄 | 小糖点 |
| 草莓球 | 草莓粉、玫红 | 三颗奶白籽 |
| 星星球 | 天蓝、宝石蓝 | 奶白星星 |
| 薄荷球 | 薄荷绿、青绿 | 小叶片 |
| 可可球 | 可可棕、奶咖 | 两条巧克力纹 |
| 彩虹球 | 淡紫、葡萄紫 | 星星和粉色糖点 |

材质主题分别使用曲奇奶霜、透明果冻、流星糖纹和宝石棱面。球体大面积使用各自颜色，拖尾也跟随对应球种。商店每个球主题同时展示完整六种球；关内球、关内购买卡、图鉴和详情共用同一个绘制器。

## 调整与新增

四套配置位于 `Assets/BuBuYiEr/Gameplay/Resources/CandyArt/BallSkins/`，分别为 `skin_milk.asset`、`skin_jelly.asset`、`skin_sunset.asset`、`skin_starry.asset`。

在 Inspector 中修改 `finish` 可选择材质主题，`colors` 的 0～5 项依次对应奶糖、草莓、星星、薄荷、可可、彩虹。每个主题都可独立调整六种颜色，无需将所有球混向同一种颜色。

新增时，创建 **Create → BuBuYiEr → Ball Theme** 资产，放在该目录，以永久商品 ID 命名；商店中添加 `category = Skin`、`effect = BallSkin`、`consumable = false` 的对应商品。未装备或缺失配置时显示各球种的默认颜色。

`CandyBallSkin` 负责主题配置与缓存；`CandyBallArt.Draw` 绘制球体和球种标记，`CandyBallArt.DrawTrail` 为关内与图鉴统一绘制拖尾。球皮肤与糖砖皮肤使用独立的装备字段。

## 验证与预览

2026-11-17，Unity 2022.3.62f2 独立工程编译及换肤检查通过。对实际渲染的球体像素进行颜色比较，默认和四个主题均保留六种不同配色；缺失主题时按球种回退。商店的四个球主题均展示完整六种球，三款新糖砖可购买、装备并通过 JSON 存档重载，球与糖砖装备互不覆盖。
