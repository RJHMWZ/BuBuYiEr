# 打赏咖啡

设置页原来的“隐私政策”入口已替换为“打赏咖啡”，图标为带粉色爱心的咖啡杯。点击后显示独立弹窗，关闭按钮为“继续开心玩”。

文案：

> 如果这个小游戏给你带来了一点快乐，
> 也欢迎请我喝杯咖啡。
> 量力而行，礼轻情意重。
> 你愿意来玩，就是很棒的支持。

弹窗展示提供的微信收款码，提示“微信扫一扫，或截图后在微信中识别”。打开与关闭弹窗不会改变游戏金币、进度或装备。

## 图片与调整

- 收款码资源：`Assets/BuBuYiEr/UI/Resources/BearSupport/CoffeeWeChat.png`。
- 从原图保留白底二维码、头像及收款人信息，去除外侧绿色区域，缩至 512×560。PNG 为 24,864 字节，原附件为 140,463 字节。
- 导入为 Sprite，使用 Point 过滤、关闭 mipmap 和有损纹理压缩，保持二维码边缘清晰。缩图后及 460、360、280 像素宽度下解码结果均与原图一致。
- 入口、图标和弹窗布局位于 `BearMenuFactory.Coffee.cs`，文案在 `CoffeeMessage` 常量中。

菜单布局版本已递增，进入游戏时会自动重建旧版菜单。

## 验证与预览

2026-11-17，Unity 2022.3.62f2 独立工程编译通过。检查覆盖旧菜单自动重建、设置页真实按钮打开弹窗、关闭及重新打开、切换回普通帮助弹窗，以及游戏存档保持不变。竖屏和长屏实际渲染画面中的二维码均可解码，内容与用户提供的原图一致。
