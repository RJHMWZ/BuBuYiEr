# 糖果打砖块玩法

核心玩法已替换为 HTML5.zip 中的放置打砖块：点击糖砖，获得本关蜂蜜；购买自动弹跳的小球，升级同类小球威力，清空棋盘后通关。主题沿用布布一二的小熊、奶油色纸张、粉色与糖果色。

## 启动

打开 `Assets/Diamond_Loop/Scenes/Home.unity`，进入 Play，点击开始游戏或选择关卡。主菜单、加载流程、糖果旅行选关、暂停与故事解锁继续沿用。

每关开始前显示规则，点击“开始打糖砖”后小球才移动。鼠标点击、触摸点击和在砖块上拖动均可造成点击伤害；每 0.09 秒最多一次。右上角暂停按钮可继续、重试或返回主页，失焦时自动暂停。

## 小球与经济

| 小球 | 特性 |
| --- | --- |
| 奶糖球 | 便宜、轻快的基础弹跳球 |
| 草莓球 | 命中时对附近糖砖造成溅射 |
| 星星球 | 在弹跳中逐渐转向最近糖砖 |
| 薄荷球 | 命中后持续融化糖砖 3 秒 |
| 可可球 | 基础威力高，击碎糖砖时穿透 |
| 彩虹球 | 命中时向附近最多三块糖砖扩散伤害 |

开局自带一个奶糖球。最多 24 球，每种小球最多升级 10 次；升级同时强化同类所有小球的伤害与速度。点击伤害也可单独升级。购买数量越多、等级越高，所需蜂蜜越多。余额不足、没有该球种、达到上限或暂停时，对应按钮不能使用。

蜂蜜是本关临时资源，重试、换关后重新准备，不扣除主菜单金币。通关奖励金币写入原 CoinManager 和玩家存档；重复结算不会重复发奖。没有倒计时失败或掉球惩罚；按完成用时给 1～3 星，较慢也可以通关。重玩保留已有最高星级。

原 101 份关卡资产的路径和 GUID 保留，内容改成糖砖配置。选关总数按实际资产数量显示。关卡递增耐久、初始蜂蜜和奖励，提供四种布局；每五关出现高耐久大糖砖。原存档的金币、关卡进度、星级、菜单偏好与收藏保留，旧道具库存字段仅保留存档兼容，不再在关内或调试面板展示。

## 编辑

选中 `Assets/Diamond_Loop/Resources/Levels/Level_编号.asset` 可修改列数、行数、耐久、布局、是否有大糖砖、开局蜂蜜、通关金币和星级用时。运行时不会再读取像素图、颜色罐或传送带配置。

- `Assets/BuBuYiEr/Gameplay/Scripts/CandyBreakoutSimulation.cs`：碰撞、六种球、伤害、蜂蜜和购买升级。
- `Assets/BuBuYiEr/Gameplay/Scripts/CandyBreakoutGraphic.cs`：批量绘制糖砖、小球、尾迹和碎屑，处理棋盘指针输入。
- `Assets/BuBuYiEr/Gameplay/Scripts/CandyBreakoutView.cs`：关内布局、规则、数值和商店。
- `Assets/Diamond_Loop/Scripts/Managers/IngameManager.cs`：开局、暂停、结算与保存。

旧的拼豆/像素关卡图、罐子与传送带脚本、专用预制体、模型、材质、特效、音效和着色器已清理；Ingame 场景只保留相机与新回合管理器。关内 UI 预制体也已移除旧道具和引导层级。

## 验证

验证入口 `ClawbearGames.EditorTools.CandyBreakoutValidation.Run` 仅用于独立工程副本；副本须预先将产品名设为 BuBuYiErBreakoutValidation；入口会校验路径与产品名，并在结束时退出编辑器，不应在正在编辑的主工程调用。验证覆盖关卡数据、真实碰撞自动通关、购买与升级约束、完整场景流转、暂停、奖励幂等、重试和下一关，并输出关内与结算预览。

手机真机触摸、刘海安全区及目标平台性能仍需打包后验收。

2026-11-06 验证结果：Unity 2022.3.62f2 独立工程副本中，101 个关卡全部通过真实伤害、购买、升级和碰撞自动通关验证；运行时、Editor 与去除 UNITY_EDITOR 后的运行时代码编译通过。完整流程验证覆盖主页 → 加载 → 选关 → 开局、棋盘 UI 射线与坐标点击、暂停输入拦截、购买、通关、金币只发一次、解锁下一关、重试及返回主页。竖屏和长屏预览已渲染并检查。
