# 手机端布局与碰撞优化

2026-11-07，已直接修改工程，保留现有美术、关卡与存档格式。

- 小球使用固定 120 Hz 步长和扫掠圆碰撞，按最早接触点及法线反射，继续完成剩余运动。修复侧面、砖角和砖缝处的错误反弹、重复伤害和嵌入；高速运动也会检测经过的砖块。
- 星星球改为高速弹跳，取消持续朝砖块转向。其他球保留溅射、持续伤害和击碎穿透等特性。
- 棋盘显示、球半径、砖块数字与输入共用等比坐标。尾迹来自实际运动记录，增加接触闪光与碎屑反馈。
- 手机关内压缩顶部信息，小球队伍改成横向滑动的一行，每屏三种；购买和升级按钮保持 144×132 的设计尺寸。小熊放在碰撞区域之外的装饰区，避免误认为参与碰撞。
- 糖砖只在同一块砖上按下并松手时造成一次点击伤害，按住不连点。拖动、移出、失焦或暂停会取消本次点击，滑过其他砖块或按钮不会触发它们。手机切后台时暂停，回来后手动继续。
- 五个菜单使用完整安全区；长屏的奖励卡片和面板延展，图鉴增加书架可视高度，底部详情与装饰随屏幕定位。返回箭头始终位于返回按钮内。
- 砖块数字只在耐久变化时更新，减少逐帧字符串分配；碰撞先做范围筛选，避免对远处砖块计算完整接触。
